# MVP-048: AI Policy Layer - Foundation

## Overview

**Priority**: P0 (Blocking)  
**Effort**: High  
**Duration**: ~2 weeks  
**Skills Required**: Go, Security, Backend Dev, Templ, ArangoDB  
**Dependencies**: MVP-044 (Roles UI Module - Complete)  
**Status**: Not Started

## Description

Implement the foundational AI Policy Layer that provides runtime governance and guardrails for AI agent operations. This addresses DORA's finding that **clear AI policies reduce friction and amplify AI benefits** across organizations. The layer enforces organizational AI stance, autonomy boundaries, and compliance requirements.

## Objectives

- ✅ Define and implement AI policy schema in ArangoDB
- ✅ Build first-run AI policy wizard for easy configuration
- ✅ Create policy evaluation engine for runtime enforcement
- ✅ Implement model and autonomy level enforcement
- ✅ Build policy status indicators in UI
- ✅ Enable audit logging for policy decisions

## Requirements

### Functional Requirements

1. **Policy Schema & Storage**
   - YAML-based policy definition structure
   - ArangoDB collection for policy documents
   - Versioning support for policy updates
   - Default policy templates by industry

2. **First-Run Policy Wizard** (6-step guided flow)
   - Step 1: Organization context (industry, compliance frameworks)
   - Step 2: Risk tolerance (conservative → innovative)
   - Step 3: Model access (approved providers, budgets)
   - Step 4: Autonomy levels (default + role overrides)
   - Step 5: Data access (classification rules, PII handling)
   - Step 6: Review & confirm

3. **Policy Engine**
   - Evaluate actions against policy rules
   - Model allowlist/denylist enforcement
   - Autonomy level boundary enforcement
   - Budget tracking and limits
   - Response time: <50ms per evaluation

4. **UI Integration**
   - Policy status indicators on agent cards
   - Autonomy level badges (L0-L4)
   - Budget usage displays
   - Policy compliance alerts

5. **Audit System**
   - Log all policy evaluations
   - Record policy violations
   - Immutable audit trail
   - Integration with existing audit infrastructure

### Non-Functional Requirements

- **Performance**: Policy evaluation <50ms
- **Scalability**: Support 1000+ concurrent policy checks
- **Reliability**: 99.9% availability
- **Security**: Policy documents encrypted at rest
- **Compliance**: SOC2, GDPR, ISO27001 ready

### Data Models

```go
// Policy document structure
type AIPolicy struct {
    Key              string                 `json:"_key,omitempty"`
    AgencyID         string                 `json:"agency_id"`
    Version          string                 `json:"version"`
    CreatedAt        time.Time              `json:"created_at"`
    UpdatedAt        time.Time              `json:"updated_at"`
    Owner            string                 `json:"owner"`
    
    // Policy configuration
    Stance           PolicyStance           `json:"stance"`
    Models           ModelPolicy            `json:"models"`
    Autonomy         AutonomyPolicy         `json:"autonomy"`
    DataAccess       DataAccessPolicy       `json:"data_access"`
    Actions          ActionPolicy           `json:"actions"`
    Risk             RiskPolicy             `json:"risk"`
    Compliance       CompliancePolicy       `json:"compliance"`
    Monitoring       MonitoringPolicy       `json:"monitoring"`
}

type PolicyStance struct {
    AdoptionLevel        string   `json:"adoption_level"`  // conservative|controlled|progressive|innovative
    RiskTolerance        string   `json:"risk_tolerance"`  // low|medium|high
    ComplianceFrameworks []string `json:"compliance_frameworks"`
}

type ModelPolicy struct {
    AllowedProviders []AllowedProvider `json:"allowed_providers"`
    DeniedProviders  []string          `json:"denied_providers"`
    FallbackBehavior string            `json:"fallback_behavior"`
}

type AllowedProvider struct {
    Provider           string   `json:"provider"`
    Models             []string `json:"models"`
    DataResidency      string   `json:"data_residency"`
    MaxTokensPerRequest int     `json:"max_tokens_per_request"`
    MonthlyBudgetUSD   float64  `json:"monthly_budget_usd"`
}

type AutonomyPolicy struct {
    DefaultLevel   string           `json:"default_level"`
    RoleOverrides  []RoleOverride   `json:"role_overrides"`
    EscalationRules []EscalationRule `json:"escalation_rules"`
}

type PolicyResult struct {
    Allowed            bool
    Reason             string
    RequiresApproval   bool
    Approvers          []string
    RequiresEscalation bool
    EscalateToLevel    string
    RiskScore          int
    AuditRequired      bool
    PolicyVersion      string
    EvaluatedAt        time.Time
    Severity           string  // info|medium|high|critical
}
```

### Integration Points

1. **AI Builder Service** (`/internal/builder/ai/`)
   ```go
   func (b *AIBuilder) ValidateModelAccess(agencyID, provider, model string) error {
       policy, err := b.policyEngine.GetPolicy(agencyID)
       result := b.policyEngine.EvaluateModelAccess(policy, provider, model)
       if !result.Allowed {
           return fmt.Errorf("model access denied: %s", result.Reason)
       }
       return nil
   }
   ```
